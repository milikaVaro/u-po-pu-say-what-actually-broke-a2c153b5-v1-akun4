# Say What Actually Broke — Entry

One line of software error copy, at most 200 characters, that tells
the user the brutal truth about what went wrong and makes them laugh.

## How it works

`main.py` writes the error line to `/output/entry.txt`.
Stdlib only, offline, deterministic.

## The error

> The database is down. We know. We are also down. Please try again after we have both had coffee.

96 characters, one line.
